# Gemma covariance research and recovery

New Gemma calibration, quantization and model-development work is owned by Afterglow. Existing Wick source code, pinned inputs, frozen campaigns and completed research artifacts are preserved. Midnight owns native serving/runtime and generated coding/cyber evaluation. No sibling code import or package dependency is introduced: Afterglow owns the scripts and tests; external checkpoint/input paths are research data supplied by plans.

The preserved real-input screen completed four source-bound fit/development captures and twelve sampled projection/expert screens (105 method/group measurements). Covariance plus native-grid ScaleSearch improved all 21 paired development target/group reconstruction proxies versus ordinary Q4 (13.6–89.9%), diagonal activation fitting (6.2–79.7%) and covariance without search (8.5–30.9%). These are 128-output-row, at-most-4096-input measurements using FP32 multiplication of BF16-dequantized weights, not assembled-model correctness or inference speed. Only three attention projections per model and three selected A4B gate/down experts were covered. G128 is unsupported for 704-channel expert down inputs. The 31B attention covariance is rank deficient with more channels than samples and positive damping. The fit/development families are disjoint calibration data, not an independent quality holdout.

`Scripts/convert-gemma-selective-covariance.py` fits every output row of selected target modules in 128-row chunks using G64 Q4 and BF16 scales/biases. The template provides all untouched weights and original per-module metadata. Full source blobs are checked against their SHA256 content-addressed maker files before and after fitting, and source configuration/tokenizers are bound to native capture fingerprints. Every unpatched template byte is compared; patched row payloads are separately SHA256-verified. Source, template and existing output directories are protected. Checkpoint publication uses new private same-parent staging. The exact staging path is recorded before copying for interruption recovery. Conversion success does not qualify generated quality, serving memory or speed.

Afterglow validation passes five bounded-source-reader tests, four checkpoint-transaction tests and two converter/native-execution fixtures. The converter fixture spans a complete 128-row chunk plus a partial final chunk, checks identical native dense and gathered expert execution, and preserves all unselected experts. An earlier fixture failed only because its shape assertion compared a tuple to a list; the corrected native checks passed in Wick and again after importing into Afterglow. Original logs remain preserved. Import origins/hashes and Afterglow's explicit staging-ownership change are recorded in `gemma-covariance-imports-v1.json` without replacing the original Afterglow import manifest.
